Phase 1: Stream Ingestion & Dual-State Relational Flattening
The objective is to ingest nested JSON data and convert it into a flat, continuously updating relational graph state without blocking the GPU.
Task 1.1: Flatten Nested JSON via Parent-Context Tracking. * Execute a recursive descent walk over incoming JSON payloads.Ensure the edge is formulated strictly as (current_node_author, parent_author_from_stack, timestamp) to guarantee edges point to the immediate parent, preventing structural collapse to the root post.
Task 1.2: Construct the Vote-Edge Layer. * Extract upvote/downvote actions and emit them as parallel edges: (Voter_ID, Target_User, Timestamp, Sentiment_Weight).Apply distinct edge_type tags so downstream WCOJ queries can selectively join over reply-edges, vote-edges, or both.
Task 1.3: Maintain Append-Only COO + Periodic CSR Rebuild. * Maintain a live, CPU-side Coordinate (COO) edge list as the append-only source of truth for all newly arriving edges.Maintain a separate, GPU-resident Compressed Sparse Row (CSR) snapshot. Fold the COO buffer into this CSR snapshot on a fixed cadence (e.g., every micro-batch) to provide the GPU with a contiguous memory structure without suffering the overhead of in-place dynamic CSR mutation.

Phase 2: GPU-Accelerated WCOJ Extraction
The objective is to execute complex, multi-way motif queries over the streaming data using hardware acceleration.
Task 2.1: Micro-Batching with Full-History Joins. * Buffer incoming edges into overlapping micro-batches (e.g., 200ms).Crucially, execute the joins for the new edges against the full accumulated CSR graph state, not just the isolated batch, ensuring motifs that span batch boundaries are perfectly captured.
Task 2.2: Execute Custom CUDA/SIMT Motif Kernels. * Deep Directed Chain ($A \rightarrow B \rightarrow C \rightarrow D$): Execute leapfrog multi-way intersections over successive out-neighbor sets, enforcing a strict time-monotonicity check ($t_{AB} < t_{BC} < t_{CD}$) to ensure actual temporal causality.Sibling Fork ($B \leftarrow A \rightarrow C, A \rightarrow D$): Intersect Node A's out-neighbor set against itself to find $\ge 2$ distinct children. Report each instance rather than collapsing them to pairs.Ping-Pong Dyad ($A \rightarrow B \rightarrow A \rightarrow B$): Perform temporal sequence matching over the multigraph edges of unordered pairs $\{A, B\}$, scanning for alternating directions within a bounded time window rather than treating it as a standard structural intersection.
Task 2.3: Histogram Load Balancing for Hub Nodes. * Compute a degree histogram over the touched nodes prior to kernel dispatch.Bucket massive "Hub" nodes (e.g., viral posts) and chunk their adjacency lists across multiple streaming multiprocessors to prevent warp starvation and macroscopic load imbalance.

Phase 3: Temporal Cascade & State Calculation
The objective is to derive the temporal dynamics of the extracted topological shapes to identify automated behavior and subgraph reactivation.
Task 3.1: Calculate Shape-Completion Time-Delta ($\Delta t$). * For every successfully extracted vertex tuple, subtract the timestamp of the first edge from the final completing edge ($\Delta t = t_{final} - t_{initial}$) to measure formation speed.
Task 3.2: Flag Structural Reactivation. * Track a "last active timestamp" per node in the persistent graph state.If the nodes comprising a newly completed Chain, Fork, or Dyad were previously dormant for a significant interval and suddenly formed the structure with a very low $\Delta t$, tag the tuple with a Reactivation_Flag = True. Cross-reference this against the true history log, not the local batch.

Phase 4: Feature Tensor Augmentation
The objective is to translate the raw relational outputs of the WCOJ engine into normalized numeric tensors for neural ingestion.
Task 4.1: Vectorize Topological Roles with Frequency Aggregation. * Map extracted node roles into categorical vectors (e.g., [Is_Root: 1, Is_Leaf: 0]).If a node assumes multiple roles across different motifs in the same batch, aggregate these using a frequency distribution or normalized sum (e.g., [Root_Freq: 0.95, Leaf_Freq: 0.05]) to prevent feature dilution caused by binary max operations.
Task 4.2: Update Cumulative Motif Participation Counts. * Increment the dynamic structural feature vectors ($x_u$) for every participating user (e.g., [New_Chains: 1, New_Forks: 0]). Maintain these as running cumulative states synced with the persistent graph history.
Task 4.3: Construct the Motif-Augmented Edge Event. * Concatenate the base edge data with the newly generated structural and temporal feature matrices:[Source_ID, Target_ID, Timestamp, Role_Data, Motif_Counts, Motif_Delta_t, Reactivation_Flag]
